# 🛒 Product Analysis

A Python-based project that fetches e-commerce product data from the [Fake Store API](https://fakestoreapi.com/) and performs exploratory data analysis using Pandas.

## 🚀 Features

- Fetches product data using a REST API
- Organizes data into a Pandas DataFrame
- Calculates total number of products and average price
- Identifies the cheapest and most expensive products
- Shows category-wise product counts

## 🛠️ Technologies Used

- Python
- Pandas
- Requests
- REST API

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vanshkataria027-del/product_analysis.git
   cd product_analysis
   ```
2. Install the dependencies:
   ```bash
   pip install pandas requests
   ```

## ▶️ Usage

Run the script:

```bash
python e_commerce.py
```

## 📊 Sample Output

- Total products
- Average price
- Cheapest product
- Most expensive product
- Number of products per category

This project demonstrates API integration, data processing, and exploratory data analysis using Python.
